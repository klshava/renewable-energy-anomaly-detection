# Data

The datasets are **not included** in this repository. Neither Kaggle listing grants clear redistribution rights (the wind dataset's licence is listed as "Unknown"; the solar dataset's as "Data files © Original Authors", checked on Kaggle in November 2026), so download them yourself from the original sources and place the CSV files in this folder.

| Dataset | Source | Files | Size on Kaggle | Kaggle licence field |
|---|---|---|---|---|
| Wind Turbine SCADA Dataset (Berk Erisen) | https://www.kaggle.com/datasets/berkerisen/wind-turbine-scada-dataset | `T1.csv` | 3.97 MB | Unknown |
| Solar Power Generation Data (Ani Kannal) | https://www.kaggle.com/datasets/anikannal/solar-power-generation-data | `Plant_1_Generation_Data.csv`, `Plant_1_Weather_Sensor_Data.csv`, `Plant_2_Generation_Data.csv`, `Plant_2_Weather_Sensor_Data.csv` | 11.23 MB | Data files © Original Authors |

A free Kaggle account is needed to download. Use the website's **Download** button, then unzip so the files sit directly in `data/` (for example `data/T1.csv`).

Please credit the dataset authors if you reuse the data, and check the Kaggle pages for current terms.

The original university notebooks fetched the files from private Dropbox copies. Those links have been removed from this repository.
